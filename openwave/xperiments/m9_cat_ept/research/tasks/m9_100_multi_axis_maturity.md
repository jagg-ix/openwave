# M9.100 task: multi-axis criterion maturity

## Problem

The historical M9 profile stores one scalar status per criterion and then tests that the distribution remains exactly `7 validated / 13 partial / 1 negative`. New exact formal and numerical results can update prose but cannot change the assessment without editing the frozen set.

## Target

Replace the scalar status as primary authority with six independent evidence axes:

1. formal theorem status;
2. numerical closure;
3. state construction;
4. physical identity;
5. calibration;
6. prediction readiness.

Derive the headline status from those axes. Retain the old scalar status only as compatibility metadata.

## Acceptance

- All 21 historical criteria are represented exactly once.
- No fixed promoted-key set is used by the current headline derivation.
- `7/13/1` is not an acceptance condition in the current profile or registration.
- The 13 legacy partial rows split into:
  - five conditional validations;
  - three reduced-model validations;
  - one calibration-pending result;
  - four candidates.
- Gravity is conditional-formal rather than reduced-model because theorem scope takes precedence over numerical carrier reduction.
- Changing evidence axes changes the derived headline in tests.
- Physical identity and calibration remain explicit independent axes and are never inferred by reclassification.

## Non-targets

- no new Lean theorem;
- no new numerical physics campaign;
- no physical particle assignment;
- no parameter calibration;
- no external prediction claim.
