# M9.106--M9.108 dynamical field campaigns

## Scope

This package completes three executable targets without conflating reduced carrier closure with physical theory closure.

### M9.106

A nonlinear conformal-ADM reduction evolves matter, Maxwell fields, conformal spatial metric, lapse, and trace extrinsic curvature. Hamiltonian and momentum constraints are measured before and after elliptic projection.

### M9.107

Three previously reduced interaction sectors gain explicit field carriers and conservation/structure gates.

### M9.108

Four open particle sectors gain relaxed, localized candidate fields and independent short-time perturbation tests.

## Reproduction

```bash
python openwave/xperiments/m9_cat_ept/research/scripts/m9_106_nonlinear_constraint_gravity.py > m9_106.json
python openwave/xperiments/m9_cat_ept/research/scripts/m9_107_coupled_sector_fields.py > m9_107.json
python openwave/xperiments/m9_cat_ept/research/scripts/m9_108_candidate_states.py > m9_108.json
```

Committed result records:


The M9.107 file records initial/final diagnostics and the SHA-256 of the complete locally executed ledger. The complete ledger is regenerated by the runner.

## Boundaries

- conformal/pure-trace ADM is not general relativity;
- a color flux field is not non-Abelian QCD;
- a chiral mediator field is not the electroweak Standard Model;
- a stable finite candidate is not a physical particle identity;
- repository program-health is not experimental evidence.
